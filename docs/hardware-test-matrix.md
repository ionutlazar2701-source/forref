# Test hardware (rental)

Do not rent as many models as possible. Rent a few watches that behave differently.
The product risk is fragmentation, not the lack of a flagship.

## Minimum set (first round)

Two Wear OS watches — the MVP platform.

1. **Samsung Galaxy Watch 6 / 7 / FE / 8 — 44 mm**
   The most common Wear OS in RO/EU. Large screen for match buttons.
   Test One UI Watch, bezel (if Classic), GPS, heart rate, vibration, battery for 90+ minutes.

2. **Google Pixel Watch 2 / 3 / 4 — 41 mm**
   Stock Wear OS, small screen (the hard UI case). Do not take the 45 mm variant.

## Extended set (4 devices)

3. **Apple Watch SE (GPS), 44 mm** — the cheap path to iPhone. No Series/Ultra.
4. **Garmin Forerunner 255** — sun + battery + Connect IQ. Prefer over 265 for the MIP display.

Optional, only if a Zepp OS build exists:

5. **Amazfit Active 2 (round) or Bip Max** — budget ~100€, GPS, Zepp OS.
   Do not take T-Rex / Balance.

## Do not rent

- Xiaomi Band / Huawei Band / CMF (they do not run the app as a product)
- Ultra (Apple Ultra, Galaxy Ultra, Fenix, T-Rex Ultra)
- LTE variants (the real case is Bluetooth + phone at the touchline)
- Two Galaxy watches from the same generation
- Redmi Watch without Wear OS

## Priority

| Priority | Model | Why |
|---|---|---|
| 1 | Galaxy Watch 6/7/FE/8 44 mm | Wear OS volume |
| 2 | Pixel Watch 41 mm | Small screen + stock Wear OS |
| 3 | Apple Watch SE 44 mm | iPhone, without Ultra cost |
| 4 | Forerunner 255 | Sun + battery + Garmin |
| 5 | Amazfit Active 2 | Budget + Zepp, only if Zepp is started |

## Real-match checklist

One outdoor match, 90 minutes + extra time, sun, sweat:

- [ ] Time digits are readable without shade
- [ ] A card is tapped on the first try while running, with a sweaty finger
- [ ] GPS does not jump off the pitch
- [ ] Battery lasts with GPS + heart rate + wake screen + vibration
- [ ] If Bluetooth drops, match data stays on the watch
